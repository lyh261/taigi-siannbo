# 毓繡的台語課・台羅拼音－聲母

台羅拼音聲母練習遊戲。看台文、聽音檔，照順序揀出兩字詞的兩个聲母。一回合 10 題，一个聲母答對 5 分，滿分 100 分。封面有最高成績，結束有所有成績紀錄（紀錄存佇各台裝置的瀏覽器內底）。

## 出處

題目、台羅拼音佮音檔攏取自教育部《臺灣台語常用詞辭典》：<https://sutian.moe.edu.tw/zh-hant/>

辭典內容的著作權屬教育部，使用請遵守辭典網站的授權規定。

## 檔案

- `index.html`：遊戲頁面
- `words.js`：題庫（329 个兩字詞）
- `audio.js`：題庫音檔（mp3，base64）
